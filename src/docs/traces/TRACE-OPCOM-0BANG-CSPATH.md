# Golden CS-path: OPCOM `0!` on ND-110 RASK microcode

- Purpose: reference for the ND-120 emulator's MOPC console blocker (nd120cpuemu HANDOFF.md 2c). Same RASK microcode runs there - diff its captured CS path against the phases below; the FIRST divergence is the emulator-side bug.
- Each row: `cycle | csar | symbol | microcode source`. csar is `hw.mic.map` AFTER the micro-cycle (address of the NEXT microinstruction), matching the ND-120 side's capture-after-Step convention.
- `LOOP xN (period P)` blocks are N back-to-back repetitions of the P-row window listed under them (idle/poll loops compressed).
- `>> UART OUT` lines mark console output emitted at that point in the stream.
- All control-store addresses OCTAL. Symbols from `ND-110-RASK.SYMBOLS.TXT` (exact label or `LABEL+n`).
